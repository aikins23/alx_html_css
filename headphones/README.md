
# Headphones Landing Page

## Project Overview
This project is a responsive landing page built from scratch using only HTML and CSS. The goal is to recreate a professional designer layout based on a Figma file. The work focuses on clean structure, accessibility, and responsive design principles.

No external CSS frameworks were used.

## Project Objectives
- Build a layout from scratch
- Follow a Figma design
- Apply responsive and accessible web design practices
- Use reusable and clean CSS

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Variables
- Media Queries

## Key Features
- CSS reset for consistent styling
- Centralized color and font variables
- Clean, reusable CSS classes
- Max content width of 1000px
- Responsive desktop and mobile layout
- Link hover and active color: `#FF6565`
- Button hover opacity: `0.9`
- Custom icon font integration
- Pure CSS geometric shapes
- CSS animations for section elements
- Mobile hamburger menu using JavaScript

## Responsive Behavior
- Desktop view for screens wider than 480px
- Mobile view for screens 480px and below
- Navigation switches to hamburger menu on small screens
